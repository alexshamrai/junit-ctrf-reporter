# Phase 3 (0.5.1): Robustness, No Runtime Dependencies, Run Ownership — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Phase 3 as patch release 0.5.1 on one branch, `fix/phase-3-robustness`, with eight commits, one per task:
- warnings go through `java.util.logging`;
- our own config loader replaces `owner`, and our own JSON code replaces Jackson, so the published POM has no dependencies;
- `message` is the exception summary and `trace` is capped;
- the extension's end-of-run hook is `AutoCloseable`;
- reporter errors never change a test's outcome;
- a nested JUnit run can't end the outer one;
- the manager's collaborators are injected, and the README recommends the listener.

**Architecture:**
- Commits 1–4 touch the core:
  - every `System.err` warning becomes a JUL warning;
  - `ConfigReader` reads system properties, the environment and `ctrf.properties` itself;
  - a new internal package, `io.github.alexshamrai.json`, writes and reads the model;
  - `TestProcessor` builds `message` and `trace` differently.
- Commits 5–6 touch only `jupiter/`:
  - a named store value, both `CloseableResource` and `AutoCloseable`, ends the run;
  - a guard catches reporter errors in every callback.
- Commit 7 gives `CtrfReportManager` at most one active `TestRun`, which remembers its owner: the listener's `TestPlan` or the extension's root `ExtensionContext`. An entry point whose run start is refused reports nothing.
- Commit 8 moves the manager's wiring into one package-private constructor, and rewrites the README's setup section.

**Tech Stack:**
- Java 17 (`--release 17`), built with the Java 21 toolchain;
- Gradle 9; JUnit 5.10.5 as the compile floor for main code, JUnit 6.1.3 for tests;
- Lombok, Mockito 5, AssertJ;
- `junit-platform-testkit` (new, test scope);
- Jackson 2.22.2, test scope only after Task 3: the oracle for the differential test, and the reader in `ScenarioRunner` and the integration validator.

## Review Focus

These are the five inputs most likely to hurt a user that the spec implies but no task's main tests exercise. Each has a test in the task that owns the code.

1. **A JVM whose default locale is Turkish** (`tr-TR`, common on Turkish CI agents).
   - `"FAILED".toLowerCase()` is `"faıled"`, with a dotless ı, so the report's status is invalid CTRF. And `"ctrf.build.url".toUpperCase()` is `"CTRF.BUİLD.URL"`, so `CTRF_BUILD_URL` would never be found.
   - Expected: statuses in English lower case; `CTRF_*` names found.
   - Tests: `ConfigReaderTest.upperCaseVariablesAreFoundUnderATurkishLocale` (Task 2) and `CtrfJsonMapperTest.statusIsWrittenInLowerCaseUnderATurkishLocale` (Task 3, with the `Locale.ROOT` fix in `Test.TestStatus`).
2. **A `ctrf.properties` saved as UTF-8 with non-ASCII values,** such as `ctrf.app.name=Zahlungsdienst Müller`.
   - `owner` 1.0.12 reads the file as UTF-8 whatever the JVM's charset (probed 2026-10-15), and turns invalid UTF-8 bytes into U+FFFD. `Properties.load(InputStream)` reads ISO-8859-1, which would turn every `ü` into `Ã¼`: a regression the spec's table doesn't list.
   - Expected: UTF-8 as before; a file that isn't valid UTF-8 is read as ISO-8859-1, instead of `owner`'s U+FFFD.
   - Tests: `ConfigReaderTest.propertiesFileIsReadAsUtf8` and `ConfigReaderTest.propertiesFileThatIsNotUtf8IsReadAsIso88591` (Task 2).
3. **A corrupt or hostile report on disk that nests very deeply,** such as 100,000 `[`.

   - Tests: `JsonParserTest.deeperNestingThrowsInsteadOfOverflowingTheStack` and `CtrfReportFileServiceTest.deeplyNestedReportIsReplaced` (Task 3).
4. **A failure whose `getMessage()` or `toString()` throws,** for example a message built lazily from a closed resource.
   - Today `printStackTrace` throws inside the reporter, and the test's entry is lost.
   - Expected: the test is reported as failed, with the exception's class name as `message`.
   - Test: `TestProcessorTest.failureWhoseToStringThrowsIsStillRecorded` (Task 4).
5. **Stack traces with Windows line endings** (`\r\n`, which `printStackTrace` writes on Windows), when `trace` is capped.
   - Expected: the cut falls after a whole `\r\n` line, and the marker and the `Caused by:` lines stay whole lines.

```java
package io.github.alexshamrai;

import org.junit.jupiter.api.extension.AfterEachCallback;
import org.junit.jupiter.api.extension.BeforeEachCallback;
import org.junit.jupiter.api.extension.ExtensionContext;

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.logging.Handler;
import java.util.logging.Level;
import java.util.logging.LogRecord;
import java.util.logging.Logger;

/**
 * Captures what one class logs through {@code java.util.logging} during each test, and keeps it off the console.
 * Register it with {@code @RegisterExtension}.
 */
public final class LogCapture implements BeforeEachCallback, AfterEachCallback {

    /**
     * Held for as long as the capture, because the logging framework keeps loggers only weakly.
     */
    private final Logger logger;
    private final List<LogRecord> records = Collections.synchronizedList(new ArrayList<>());
    private final Handler handler = new Handler() {
        @Override
        public void publish(LogRecord record) {
            records.add(record);
        }

        @Override
        public void flush() {
            // Nothing is buffered
        }

        @Override
        public void close() {
            // Nothing to release
        }
    };
    private boolean usedParentHandlers;

    /**
     * Captures the logger named after the given class, which is the logger that class logs to.
     *
     * @param loggingClass the class whose warnings to capture
     */
    public LogCapture(Class<?> loggingClass) {
        this.logger = Logger.getLogger(loggingClass.getName());
        handler.setLevel(Level.ALL);
    }

    @Override
    public void beforeEach(ExtensionContext context) {
        records.clear();
        usedParentHandlers = logger.getUseParentHandlers();
        logger.setUseParentHandlers(false);
        logger.addHandler(handler);
    }

    @Override
    public void afterEach(ExtensionContext context) {
        logger.removeHandler(handler);
        logger.setUseParentHandlers(usedParentHandlers);
    }

    /**
     * Returns the records captured in this test, oldest first.
     *
     * @return a copy of the records
     */
    public List<LogRecord> records() {
        synchronized (records) {
            return new ArrayList<>(records);
        }
    }

    /**
     * Returns the messages captured in this test, oldest first.
     *
     * @return the messages
     */
    public List<String> messages() {
        return records().stream().map(LogRecord::getMessage).toList();
    }

    /**
     * Returns the messages captured in this test, one per line.
     *
     * @return the messages, or an empty string if nothing was logged
     */
    public String text() {
        return String.join("\n", messages());
    }
}
```

~~~markdown
## Logging

The reporter logs warnings, for example about a report it can't read or lock, through `java.util.logging`. Its loggers are named after its classes, which all start with `io.github.alexshamrai`. By default the warnings go to the standard error.

handlers = java.util.logging.ConsoleHandler

If your project routes `java.util.logging` to SLF4J or Log4j, for example with `jul-to-slf4j`, the warnings go there.
~~~

```java
    private static ConfigReader readWithPropertiesFrom(Path directory) throws Exception {
```

```java
import java.io.IOException;
import java.io.InputStream;
import java.io.StringReader;
import java.nio.ByteBuffer;
import java.nio.charset.CharacterCodingException;

/**
 * Reads the reporter's configuration, once, when it is created.
 * <p>
 * Each key is looked up in these sources, and the first one that sets it wins:
 * <ol>
 *   <li>the system property, such as {@code ctrf.report.path};</li>
 *   <li>the environment variable with the same name, then, for a {@code ctrf.*} key, the name in upper case with
 *       underscores, such as {@code CTRF_REPORT_PATH};</li>
 *   <li>{@code ctrf.properties} on the classpath, found through the context class loader, then through the library's
 *       own. It is read as UTF-8, or as ISO-8859-1 if it isn't valid UTF-8;</li>
 *   <li>the key's default.</li>
 * </ol>
 * A value can use any name these sources set as {@code ${name}}, which is looked up the same way; a name that nothing
 * sets expands to an empty string. A number or a boolean that can't be read, or a negative length, logs a warning and
 * the default is used.
 */
public class ConfigReader {

    private static final Logger LOGGER = Logger.getLogger(ConfigReader.class.getName());
    private static final String PROPERTIES_FILE = "ctrf.properties";
    private static final String CTRF_PREFIX = "ctrf.";
    private static final Pattern REFERENCE = Pattern.compile("\\$\\{(.+?)}");

    private static final String REPORT_PATH = "ctrf.report.path";
    private static final String MAX_MESSAGE_LENGTH = "ctrf.max.message.length";
    private static final String CALCULATE_STARTUP_DURATION = "ctrf.calculate.startup.duration";
    private static final Map<String, String> DEFAULTS = Map.of(
        REPORT_PATH, "ctrf-report.json",
        MAX_MESSAGE_LENGTH, "500",
        CALCULATE_STARTUP_DURATION, "false");

    private final Map<String, String> systemProperties;
    private final Map<String, String> environment;
    private final Map<String, String> fileProperties;

    private final String reportPath;
    private final int maxMessageLength;
    private final String junitVersion;
    private final String reportName;
    private final String appName;
    private final String appVersion;
    private final String buildName;
    private final String buildNumber;
    private final String buildUrl;
    private final String repositoryName;
    private final String repositoryUrl;
    private final String commit;
    private final String branchName;
    private final String osPlatform;
    private final String osRelease;
    private final String osVersion;
    private final String testEnvironment;
    private final boolean calculateStartupDuration;
    private final String runId;

    /**
     * Creates a reader of this JVM's system properties, its environment variables and {@code ctrf.properties}.
     */
    public ConfigReader() {
        this(toMap(System.getProperties()), System.getenv(), loadPropertiesFile());
    }

    /**
     * Creates a reader of the given sources only, for tests and for code that runs the reporter itself.
     *
     * @param systemProperties the system properties
     * @param environment      the environment variables
     * @param fileProperties   the contents of {@code ctrf.properties}
     */
    public ConfigReader(Map<String, String> systemProperties, Map<String, String> environment,
                        Map<String, String> fileProperties) {
        this.systemProperties = Map.copyOf(systemProperties);
        this.environment = Map.copyOf(environment);
        this.fileProperties = Map.copyOf(fileProperties);

        this.reportPath = string(REPORT_PATH);
        this.maxMessageLength = length(MAX_MESSAGE_LENGTH);

    /**
     * A length: a whole number of 0 or more, with spaces around it allowed. Anything else warns and gives the default.
     */
    private int length(String key) {
        String value = string(key);
        int fallback = Integer.parseInt(DEFAULTS.get(key));
        try {
            int parsed = Integer.parseInt(value.strip());
            if (parsed >= 0) {
                return parsed;
            }
        } catch (NumberFormatException e) {
            // Warned below
        }
        LOGGER.warning(key + " must be a whole number of 0 or more, but is \"" + value + "\"; using the default, " + fallback);
        return fallback;
    }

    /**
     * A boolean: true or false in any case, with spaces around it allowed. Anything else warns and gives the default.
     */
    private boolean bool(String key) {
        String value = string(key);
        String trimmed = value.strip();
        if ("true".equalsIgnoreCase(trimmed) || "false".equalsIgnoreCase(trimmed)) {
            return Boolean.parseBoolean(trimmed);
        }
        boolean fallback = Boolean.parseBoolean(DEFAULTS.get(key));
        LOGGER.warning(key + " must be true or false, but is \"" + value + "\"; using the default, " + fallback);
        return fallback;
    }

    /**
     * The value of a key with its references expanded, or {@code null} if no source sets it and it has no default.
     *
     * @param resolving the keys being expanded, to detect a reference back to one of them
     */
    private String resolve(String key, Set<String> resolving) {
        String raw = rawValue(key);
        if (raw == null) {
            return null;
        }
        resolving.add(key);
        try {
            return expand(raw, resolving);
        } finally {
            resolving.remove(key);
        }
    }

    private String expand(String value, Set<String> resolving) {
        Matcher reference = REFERENCE.matcher(value);
        StringBuilder expanded = new StringBuilder();
        while (reference.find()) {
            String name = reference.group(1);
            String replacement;
            if (resolving.contains(name)) {
                LOGGER.warning("${" + name + "} refers back to itself in the CTRF configuration, so it expands to an empty string");
                replacement = "";
            } else {
                String resolved = resolve(name, resolving);
                replacement = resolved != null ? resolved : "";
            }
            reference.appendReplacement(expanded, Matcher.quoteReplacement(replacement));
        }
        reference.appendTail(expanded);
        return expanded.toString();
    }

    private String rawValue(String key) {
        String value = systemProperties.get(key);
        if (value == null) {
            value = environment.get(key);
        }
        if (value == null && key.startsWith(CTRF_PREFIX)) {
            // Locale.ROOT: under a Turkish locale, "i" would become a dotted capital I
            value = environment.get(key.toUpperCase(Locale.ROOT).replace('.', '_'));
        }
        if (value == null) {
            value = fileProperties.get(key);
        }
        return value != null ? value : DEFAULTS.get(key);
    }

    private static Map<String, String> loadPropertiesFile() {
        try (InputStream in = openPropertiesFile()) {
            if (in == null) {
                return Map.of();
            }
            var properties = new Properties();
            properties.load(new StringReader(decode(in.readAllBytes())));
            return toMap(properties);
        } catch (IOException | IllegalArgumentException e) {
            LOGGER.warning(PROPERTIES_FILE + " can't be read, so it is ignored - " + e.getMessage());
            return Map.of();
        }
    }

    private static InputStream openPropertiesFile() {
        ClassLoader context = Thread.currentThread().getContextClassLoader();
        InputStream in = context != null ? context.getResourceAsStream(PROPERTIES_FILE) : null;
        return in != null ? in : ConfigReader.class.getClassLoader().getResourceAsStream(PROPERTIES_FILE);
    }

    // UTF-8, as owner read it; ISO-8859-1, the traditional encoding of .properties files, when it isn't valid UTF-8
    private static String decode(byte[] bytes) {
        try {
            return StandardCharsets.UTF_8.newDecoder()
                .onMalformedInput(CodingErrorAction.REPORT)
                .onUnmappableCharacter(CodingErrorAction.REPORT)
                .decode(ByteBuffer.wrap(bytes))
                .toString();
        } catch (CharacterCodingException e) {
            return new String(bytes, StandardCharsets.ISO_8859_1);
        }
    }

    private static Map<String, String> toMap(Properties properties) {
        Map<String, String> map = new HashMap<>();
        for (String name : properties.stringPropertyNames()) {
            map.put(name, properties.getProperty(name));
        }
        return map;
    }
```

```java
package io.github.alexshamrai.json;

import java.util.Map;

/**
 * Writes JSON values as compact text, with no whitespace between tokens.
 * <p>
 * It writes {@code null}, {@link String}, {@link Boolean}, {@link Number}, {@link Map} with {@code String} keys and
 * {@link Iterable}. Strings are escaped as Jackson escapes them: the quotation mark and the backslash, the short
 * escapes for backspace, tab, newline, form feed and carriage return, and a six-character escape with upper-case hex
 * digits for the other control characters. Every other character is written as it is. A surrogate without its pair,
 * which UTF-8 can't encode, is written as a six-character escape too. A double or a float that isn't finite is
 * written as a string, such as {@code "NaN"}, as Jackson writes it.
 */
public final class JsonWriter {

    private static final char[] HEX_DIGITS = "0123456789ABCDEF".toCharArray();

    private JsonWriter() {
        // Utility class - prevent instantiation
    }

    /**
     * Writes a JSON value.
     *
     * @param value the value
     * @return its JSON text
     * @throws JsonException if the value, or a value inside it, has no JSON form
     */
    public static String write(Object value) {
        var out = new StringBuilder();
        writeValue(value, out);
        return out.toString();
    }

    private static void writeValue(Object value, StringBuilder out) {
        if (value == null) {
            out.append("null");
        } else if (value instanceof String text) {
            writeString(text, out);
        } else if (value instanceof Boolean) {
            out.append(value);
        } else if (value instanceof Number number) {
            writeNumber(number, out);
        } else if (value instanceof Map<?, ?> object) {
            writeObject(object, out);
        } else if (value instanceof Iterable<?> array) {
            writeArray(array, out);
        } else {
            throw new JsonException("No JSON form for a " + value.getClass().getName());
        }
    }

    private static void writeNumber(Number number, StringBuilder out) {
        boolean floatingPoint = number instanceof Double || number instanceof Float;
        if (floatingPoint && !Double.isFinite(number.doubleValue())) {
            writeString(number.toString(), out);
        } else {
            out.append(number);
        }
    }

    private static void writeObject(Map<?, ?> object, StringBuilder out) {
        out.append('{');
        boolean first = true;
        for (Map.Entry<?, ?> member : object.entrySet()) {
            if (!(member.getKey() instanceof String name)) {
                throw new JsonException("A JSON member name must be a string, not " + member.getKey());
            }
            if (!first) {
                out.append(',');
            }
            first = false;
            writeString(name, out);
            out.append(':');
            writeValue(member.getValue(), out);
        }
        out.append('}');
    }

    private static void writeArray(Iterable<?> array, StringBuilder out) {
        out.append('[');
        boolean first = true;
        for (Object element : array) {
            if (!first) {
                out.append(',');
            }
            first = false;
            writeValue(element, out);
        }
        out.append(']');
    }

    private static void writeString(String text, StringBuilder out) {
        out.append('"');
        int i = 0;
        while (i < text.length()) {
            char c = text.charAt(i);
            if (c == '"' || c == '\\') {
                out.append('\\').append(c);
            } else if (c < 0x20) {
                writeControlCharacter(c, out);
            } else if (Character.isHighSurrogate(c) && i + 1 < text.length() && Character.isLowSurrogate(text.charAt(i + 1))) {
                out.append(c).append(text.charAt(i + 1));
                i++;
            } else if (Character.isSurrogate(c)) {
                writeUnicodeEscape(c, out);
            } else {
                out.append(c);
            }
            i++;
        }
        out.append('"');
    }

    private static void writeControlCharacter(char c, StringBuilder out) {
        switch (c) {
            case '\b':
                out.append("\\b");
                break;
            case '\t':
                out.append("\\t");
                break;
            case '\n':
                out.append("\\n");
                break;
            case '\f':
                out.append("\\f");
                break;
            case '\r':
                out.append("\\r");
                break;
            default:
                writeUnicodeEscape(c, out);
        }
    }

    private static void writeUnicodeEscape(char c, StringBuilder out) {
        out.append("\\u")
            .append(HEX_DIGITS[(c >> 12) & 0xF])
            .append(HEX_DIGITS[(c >> 8) & 0xF])
            .append(HEX_DIGITS[(c >> 4) & 0xF])
            .append(HEX_DIGITS[c & 0xF]);
    }
}
```

```java
package io.github.alexshamrai.json;

import java.math.BigInteger;
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

/**
 * Parses JSON text into {@code null}, {@link String}, {@link Boolean}, {@link Integer}, {@link Long},
 * {@link BigInteger}, {@link Double}, {@link LinkedHashMap} and {@link ArrayList}.
 * <p>
 * A whole number becomes the smallest of {@code Integer}, {@code Long} and {@code BigInteger} that holds it, and any
 * other number a {@code Double}, as Jackson reads numbers into {@code Object}. An object keeps its members in order,
 * and a repeated name keeps its last value. Whitespace may surround any token, and the text may start with a byte
 * order mark. Anything else that isn't strict JSON throws. So do a number longer than 1000 characters and nesting
 * deeper than 1000 levels, which would otherwise take minutes or overflow the stack.
 */
public final class JsonParser {

    /**
     * How deep arrays and objects may nest.
     */
    static final int MAX_DEPTH = 1000;

    /**
     * How many characters a number may have, as with Jackson.
     */
    static final int MAX_NUMBER_LENGTH = 1000;

    private static final char BYTE_ORDER_MARK = (char) 0xFEFF;

    private final String text;
    private int position;
    private int depth;

    private JsonParser(String text) {
        this.text = text;
    }

    /**
     * Parses one JSON value.
     *
     * @param text the JSON text
     * @return the value
     * @throws JsonException if the text isn't exactly one JSON value
     */
    public static Object parse(String text) {
        var parser = new JsonParser(text);
        if (parser.peek(BYTE_ORDER_MARK)) {
            parser.position++;
        }
        parser.skipWhitespace();
        Object value = parser.readValue();
        parser.skipWhitespace();
        if (parser.position < text.length()) {
            throw parser.error("Unexpected text after the JSON value");
        }
        return value;
    }

    private Object readValue() {
        if (position >= text.length()) {
            throw error("Unexpected end of the JSON text");
        }
        char c = text.charAt(position);
        switch (c) {
            case '{':
                return readObject();
            case '[':
                return readArray();
            case '"':
                return readString();
            case 't':
                readWord("true");
                return Boolean.TRUE;
            case 'f':
                readWord("false");
                return Boolean.FALSE;
            case 'n':
                readWord("null");
                return null;
            default:
                if (c == '-' || isDigit(c)) {
                    return readNumber();
                }
                throw error("Unexpected character '" + c + "'");
        }
    }

    private Map<String, Object> readObject() {
        enterNesting();
        position++;
        Map<String, Object> object = new LinkedHashMap<>();
        skipWhitespace();
        if (peek('}')) {
            position++;
            depth--;
            return object;
        }
        while (true) {
            skipWhitespace();
            if (!peek('"')) {
                throw error("Expected a member name");
            }
            String name = readString();
            skipWhitespace();
            expect(':');
            skipWhitespace();
            object.put(name, readValue());
            skipWhitespace();
            if (!peek(',')) {
                expect('}');
                depth--;
                return object;
            }
            position++;
        }
    }

    private List<Object> readArray() {
        enterNesting();
        position++;
        List<Object> array = new ArrayList<>();
        skipWhitespace();
        if (peek(']')) {
            position++;
            depth--;
            return array;
        }
        while (true) {
            skipWhitespace();
            array.add(readValue());
            skipWhitespace();
            if (!peek(',')) {
                expect(']');
                depth--;
                return array;
            }
            position++;
        }
    }

    private String readString() {
        position++;
        var out = new StringBuilder();
        while (true) {
            if (position >= text.length()) {
                throw error("Unterminated string");
            }
            char c = text.charAt(position++);
            if (c == '"') {
                return out.toString();
            } else if (c == '\\') {
                readEscape(out);
            } else if (c < 0x20) {
                throw error("Unescaped control character in a string");
            } else {
                out.append(c);
            }
        }
    }

    private void readEscape(StringBuilder out) {
        if (position >= text.length()) {
            throw error("Unterminated escape");
        }
        char c = text.charAt(position++);
        switch (c) {
            case '"':
            case '\\':
            case '/':
                out.append(c);
                break;
            case 'b':
                out.append('\b');
                break;
            case 'f':
                out.append('\f');
                break;
            case 'n':
                out.append('\n');
                break;
            case 'r':
                out.append('\r');
                break;
            case 't':
                out.append('\t');
                break;
            case 'u':
                out.append(readHexCharacter());
                break;
            default:
                throw error("Invalid escape \\" + c);
        }
    }

    private char readHexCharacter() {
        if (position + 4 > text.length()) {
            throw error("Truncated \\u escape");
        }
        int value = 0;
        for (int i = 0; i < 4; i++) {
            int digit = hexValue(text.charAt(position + i));
            if (digit < 0) {
                throw error("Invalid \\u escape");
            }
            value = value * 16 + digit;
        }
        position += 4;
        return (char) value;
    }

    private static int hexValue(char c) {
        if (c >= '0' && c <= '9') {
            return c - '0';
        }
        if (c >= 'a' && c <= 'f') {
            return c - 'a' + 10;
        }
        if (c >= 'A' && c <= 'F') {
            return c - 'A' + 10;
        }
        return -1;
    }

    private Number readNumber() {
        int start = position;
        boolean whole = true;
        if (peek('-')) {
            position++;
        }
        if (peek('0')) {
            position++;
        } else {
            readDigits();
        }
        if (peek('.')) {
            whole = false;
            position++;
            readDigits();
        }
        if (peek('e') || peek('E')) {
            whole = false;
            position++;
            if (peek('+') || peek('-')) {
                position++;
            }
            readDigits();
        }
        if (position - start > MAX_NUMBER_LENGTH) {
            throw error("Number longer than " + MAX_NUMBER_LENGTH + " characters");
        }
        String number = text.substring(start, position);
        return whole ? wholeNumber(number) : Double.valueOf(number);
    }

    private void readDigits() {
        if (position >= text.length() || !isDigit(text.charAt(position))) {
            throw error("Expected a digit");
        }
        while (position < text.length() && isDigit(text.charAt(position))) {
            position++;
        }
    }

    private static Number wholeNumber(String digits) {
        var value = new BigInteger(digits);
        if (value.bitLength() < Integer.SIZE) {
            return value.intValue();
        }
        if (value.bitLength() < Long.SIZE) {
            return value.longValue();
        }
        return value;
    }

    private void readWord(String word) {
        if (!text.startsWith(word, position)) {
            throw error("Expected " + word);
        }
        position += word.length();
    }

    private void expect(char c) {
        if (!peek(c)) {
            throw error("Expected '" + c + "'");
        }
        position++;
    }

    private boolean peek(char c) {
        return position < text.length() && text.charAt(position) == c;
    }

    private static boolean isDigit(char c) {
        return c >= '0' && c <= '9';
    }

    private void skipWhitespace() {
        while (position < text.length()) {
            char c = text.charAt(position);
            if (c != ' ' && c != '\t' && c != '\n' && c != '\r') {
                return;
            }
            position++;
        }
    }

    private void enterNesting() {
        depth++;
        if (depth > MAX_DEPTH) {
            throw error("Arrays and objects nest deeper than " + MAX_DEPTH + " levels");
        }
    }

    private JsonException error(String problem) {
        return new JsonException(problem + " at character " + position);
    }
}
```

```java
package io.github.alexshamrai.json;

import io.github.alexshamrai.ctrf.model.Test;

import java.lang.reflect.Field;
import java.lang.reflect.Modifier;
import java.lang.reflect.ParameterizedType;
import java.lang.reflect.Type;
import java.math.BigInteger;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

/**
 * Writes the CTRF model as JSON and reads it back, without a JSON library.
 * <p>
 * The model is the classes of {@code io.github.alexshamrai.ctrf.model}. Each is bound field by field, in declaration
 * order, under the field's name; static fields are skipped. The rules are what the model's Jackson annotations do,
 * written out here because the annotations aren't on the classpath at run time:
 * <ul>
 *   <li>writing: a null field is left out, an empty list is kept, a primitive field is always written, and a null
 *       inside a map or a list is written as {@code null};</li>
 *   <li>a test status is written in lower case, and read ignoring case; an unknown status can't be read;</li>
 *   <li>reading: a string holding a whole number fills a number field, a number or a boolean fills a text field,
 *       {@code null} fills a primitive field with 0 or false, {@code filepath} fills {@code filePath}, and unknown
 *       fields are ignored.</li>
 * </ul>
 * In the values of a {@code Map<String, Object>} or {@code List<Object>} field, a model object is written as one,
 * an enum constant as its name, and any other object that has no JSON form as its {@code toString()}.
 */
public final class CtrfJsonMapper {

    private static final String MODEL_PACKAGE = "io.github.alexshamrai.ctrf.model";

    /**
     * Other names a field is read from: reports written before 0.5.0 call {@code filePath} {@code filepath}.
     */
    private static final Map<String, String> ALIASES = Map.of("filepath", "filePath");

    private static final ClassValue<Map<String, Field>> FIELDS = new ClassValue<>() {
        @Override
        protected Map<String, Field> computeValue(Class<?> type) {
            Map<String, Field> fields = new LinkedHashMap<>();
            for (Field field : type.getDeclaredFields()) {
                if (!Modifier.isStatic(field.getModifiers()) && !field.isSynthetic()) {
                    field.setAccessible(true);
                    fields.put(field.getName(), field);
                }
            }
            return fields;
        }
    };

    private CtrfJsonMapper() {
        // Utility class - prevent instantiation
    }

    /**
     * Writes a model object as compact JSON.
     *
     * @param model an object of a model class
     * @return its JSON text
     * @throws JsonException if a value in it can't be written
     */
    public static String write(Object model) {
        return JsonWriter.write(toJsonValue(model));
    }

    /**
     * Reads JSON text into a model class.
     *
     * @param json the JSON text
     * @param type the model class
     * @param <T>  the model class
     * @return the model object, or {@code null} if the text is {@code null}
     * @throws JsonException if the text isn't valid JSON, or doesn't fit the model
     */
    public static <T> T read(String json, Class<T> type) {
        return type.cast(fromJsonValue(JsonParser.parse(json), type, "$"));
    }

    private static Object toJsonValue(Object value) {
        if (value == null || value instanceof String || value instanceof Boolean || value instanceof Number) {
            return value;
        }
        if (value instanceof Test.TestStatus status) {
            return status.toLowerCase();
        }
        if (value instanceof Enum<?> constant) {
            return constant.name();
        }
        if (value instanceof Map<?, ?> map) {
            Map<String, Object> object = new LinkedHashMap<>();
            map.forEach((key, entry) -> object.put(String.valueOf(key), toJsonValue(entry)));
            return object;
        }
        if (value instanceof Iterable<?> items) {
            List<Object> array = new ArrayList<>();
            items.forEach(item -> array.add(toJsonValue(item)));
            return array;
        }
        if (value instanceof Object[] items) {
            return toJsonValue(Arrays.asList(items));
        }
        if (isModel(value.getClass())) {
            return modelToJson(value);
        }
        return value.toString();
    }

    private static Map<String, Object> modelToJson(Object model) {
        Map<String, Object> object = new LinkedHashMap<>();
        for (Field field : FIELDS.get(model.getClass()).values()) {
            Object value = get(field, model);
            if (value != null) {
                object.put(field.getName(), toJsonValue(value));
            }
        }
        return object;
    }

    private static Object fromJsonValue(Object json, Type type, String path) {
        Class<?> raw = rawClass(type);
        if (json == null) {
            return nullValueOf(raw);
        }
        if (raw == String.class) {
            return toText(json, path);
        }
        if (raw == int.class || raw == Integer.class) {
            return toInt(json, path);
        }
        if (raw == long.class || raw == Long.class) {
            return toLong(json, path);
        }
        if (raw == boolean.class || raw == Boolean.class) {
            return toBoolean(json, path);
        }
        if (raw == Test.TestStatus.class) {
            return toStatus(json, path);
        }
        if (raw == List.class) {
            return toList(json, elementType(type), path);
        }
        if (raw == Map.class) {
            return toMap(json, path);
        }
        if (raw == Object.class) {
            return json;
        }
        if (isModel(raw)) {
            return toModel(json, raw, path);
        }
        throw new JsonException(path + ": the model has a field of a type this mapper can't read, " + raw.getName());
    }

    private static Object nullValueOf(Class<?> type) {
        if (type == int.class) {
            return 0;
        }
        if (type == long.class) {
            return 0L;
        }
        if (type == boolean.class) {
            return false;
        }
        return null;
    }

    private static Object toModel(Object json, Class<?> type, String path) {
        if (!(json instanceof Map<?, ?> object)) {
            throw new JsonException(path + ": expected an object");
        }
        Object model = newInstance(type);
        Map<String, Field> fields = FIELDS.get(type);
        for (Map.Entry<?, ?> member : object.entrySet()) {
            String name = (String) member.getKey();
            Field field = fields.get(ALIASES.getOrDefault(name, name));
            if (field != null) {
                set(field, model, fromJsonValue(member.getValue(), field.getGenericType(), path + "." + name));
            }
        }
        return model;
    }

    private static String toText(Object json, String path) {
        if (json instanceof String text) {
            return text;
        }
        if (json instanceof Number || json instanceof Boolean) {
            return json.toString();
        }
        throw new JsonException(path + ": expected a string");
    }

    private static int toInt(Object json, String path) {
        long value = toLong(json, path);
        if (value < Integer.MIN_VALUE || value > Integer.MAX_VALUE) {
            throw new JsonException(path + ": " + json + " is out of range");
        }
        return (int) value;
    }

    private static long toLong(Object json, String path) {
        if (json instanceof Integer || json instanceof Long) {
            return ((Number) json).longValue();
        }
        try {
            if (json instanceof BigInteger number) {
                return number.longValueExact();
            }
            if (json instanceof Double number) {
                return wholePart(number);
            }
            if (json instanceof String text) {
                // 0.4.x reports wrote buildNumber as a string
                return Long.parseLong(text.strip());
            }
        } catch (ArithmeticException | NumberFormatException e) {
            throw new JsonException(path + ": \"" + json + "\" is not a whole number in range", e);
        }
        throw new JsonException(path + ": expected a number, not " + json);
    }

    // A decimal read into a whole-number field keeps its whole part, as with Jackson
    private static long wholePart(double number) {
        if (!Double.isFinite(number) || number < Long.MIN_VALUE || number >= -(double) Long.MIN_VALUE) {
            throw new ArithmeticException("out of range");
        }
        return (long) number;
    }

    private static boolean toBoolean(Object json, String path) {
        if (json instanceof Boolean value) {
            return value;
        }
        if (json instanceof String text && ("true".equalsIgnoreCase(text.strip()) || "false".equalsIgnoreCase(text.strip()))) {
            return Boolean.parseBoolean(text.strip());
        }
        if (json instanceof Integer || json instanceof Long) {
            return ((Number) json).longValue() != 0;
        }
        throw new JsonException(path + ": expected true or false, not " + json);
    }

    private static Test.TestStatus toStatus(Object json, String path) {
        if (json instanceof String text) {
            for (Test.TestStatus status : Test.TestStatus.values()) {
                if (status.name().equalsIgnoreCase(text)) {
                    return status;
                }
            }
        }
        throw new JsonException(path + ": unknown test status " + json);
    }

    private static List<Object> toList(Object json, Type elementType, String path) {
        if (!(json instanceof List<?> items)) {
            throw new JsonException(path + ": expected an array");
        }
        List<Object> list = new ArrayList<>(items.size());
        for (int i = 0; i < items.size(); i++) {
            list.add(fromJsonValue(items.get(i), elementType, path + "[" + i + "]"));
        }
        return list;
    }

    @SuppressWarnings("unchecked")
    private static Map<String, Object> toMap(Object json, String path) {
        if (!(json instanceof Map)) {
            throw new JsonException(path + ": expected an object");
        }
        // The parser's objects are LinkedHashMaps with string keys
        return (Map<String, Object>) json;
    }

    private static Class<?> rawClass(Type type) {
        if (type instanceof Class<?> raw) {
            return raw;
        }
        if (type instanceof ParameterizedType parameterized) {
            return (Class<?>) parameterized.getRawType();
        }
        return Object.class;
    }

    private static Type elementType(Type listType) {
        return listType instanceof ParameterizedType parameterized ? parameterized.getActualTypeArguments()[0] : Object.class;
    }

    private static boolean isModel(Class<?> type) {
        return MODEL_PACKAGE.equals(type.getPackageName()) && !type.isEnum() && !type.isInterface();
    }

    private static Object newInstance(Class<?> type) {
        try {
            return type.getDeclaredConstructor().newInstance();
        } catch (ReflectiveOperationException e) {
            throw new JsonException("Can't create a " + type.getName(), e);
        }
    }

    private static Object get(Field field, Object model) {
        try {
            return field.get(model);
        } catch (IllegalAccessException e) {
            throw new JsonException("Can't read " + field, e);
        }
    }

    private static void set(Field field, Object model, Object value) {
        try {
            field.set(model, value);
        } catch (IllegalAccessException e) {
            throw new JsonException("Can't set " + field, e);
        }
    }
}
```

```java
    /**
     * Caps a printed stack trace at {@code maxLength} characters, 0 meaning no limit. A longer trace keeps the whole
     * lines that fit, then a line saying how many characters were cut, then every "Caused by:" line of the cut part,
     * so that the root cause stays visible. A line longer than the limit, whether the first line or a "Caused by:"
     * line, is cut at the limit. The added lines end like the trace's own, with "\r\n" or "\n".
     *
     * @param trace     the printed stack trace
     * @param maxLength the limit, or 0
     * @return the trace, capped
     */
    static String capTrace(String trace, int maxLength) {
        if (maxLength == 0 || trace.length() <= maxLength) {
            return trace;
        }
        String newline = trace.contains("\r\n") ? "\r\n" : "\n";
        int headEnd = trace.lastIndexOf('\n', maxLength - 1) + 1;
        String head = headEnd > 0 ? trace.substring(0, headEnd) : trace.substring(0, maxLength) + newline;
        String cut = trace.substring(headEnd > 0 ? headEnd : maxLength);
        var capped = new StringBuilder(head)
            .append("... ").append(cut.length()).append(" characters truncated (ctrf.max.trace.length=")
            .append(maxLength).append(')').append(newline);
        cut.lines()
            .filter(line -> line.strip().startsWith(CAUSED_BY))
            .forEach(line -> capped.append(line.length() > maxLength ? line.substring(0, maxLength) : line).append(newline));
        return capped.toString();
    }

    private static String truncate(String message, int maxLength) {
        return message.length() > maxLength ? message.substring(0, maxLength) + "..." : message;
    }

    // A failure whose toString() throws or returns null is still reported, by its class name
    private static String describe(Throwable cause) {
        try {
            String text = cause.toString();
            return text != null ? text : cause.getClass().getName();
        } catch (RuntimeException e) {
            return cause.getClass().getName();
        }
    }

    // printStackTrace starts with the failure's toString(), so it throws when that throws
    private static String stackTraceOf(Throwable cause) {
        var writer = new StringWriter();
        try {
            cause.printStackTrace(new PrintWriter(writer));
        } catch (RuntimeException e) {
            return describe(cause);
        }
        return writer.toString();
    }
```

```java
package io.github.alexshamrai.jupiter;

import io.github.alexshamrai.CtrfReportManager;
import io.github.alexshamrai.adapter.ExtensionContextAdapter;
import io.github.alexshamrai.model.TestDetails;
import org.junit.jupiter.api.extension.AfterAllCallback;
import org.junit.jupiter.api.extension.BeforeEachCallback;
import org.junit.jupiter.api.extension.ExtensionContext;
import org.junit.jupiter.api.extension.TestWatcher;

import java.util.Optional;
import java.util.logging.Level;
import java.util.logging.Logger;

/**
 * JUnit 5 extension that generates test reports in the CTRF (Common Test Report Format) format.
 * <p>
 * This extension tracks test execution, captures test results, and generates a JSON report
 * following the CTRF standard. It handles test statuses, and captures relevant test metadata.
 * <p>
 * To use this extension, simply add it to your test class using the {@code @ExtendWith} annotation:
 * <pre>
 * {@code
 * @ExtendWith(CtrfExtension.class)
 * public class MyTest {
 * // test methods
 * }
 * }
 * </pre>
 * <p>
 * A failure of a whole test class is reported as one failed entry for that class, identified by the class's
 * unique ID: "initializationError" when the class failed before any of its tests started or were skipped
 * (for example in {@code @BeforeAll} or in another extension's {@code BeforeAllCallback}), "teardownError"
 * when it failed afterwards (for example in {@code @AfterAll}).
 * <p>
 * The extension learns about a class failure only when JUnit runs the class's {@code AfterAllCallback}s,
 * so it cannot see:
 * <ul>
 *   <li>a class that could not be created: with {@code @TestInstance(Lifecycle.PER_CLASS)}, a failing
 *       constructor or {@code TestInstancePostProcessor} (for example a Spring context that fails to load)
 *       stops the class before any callback runs, and the report shows no failure for it;</li>
 *   <li>failures of containers below class level, such as a {@code @MethodSource} that throws;</li>
 *   <li>teardown failures of extensions registered before it, whose callbacks run after its own.</li>
 * </ul>
 * The JUnit Platform listener {@code io.github.alexshamrai.launcher.CtrfListener} reports all of these.
 * <p>
 * Tests of a class that JUnit skips as a whole, such as a {@code @Disabled} class or a class disabled by a
 * class-level condition, never reach the extension and are missing from its report. The JUnit Platform
 * listener {@code io.github.alexshamrai.launcher.CtrfListener} reports them as skipped.
 * <p>
 * The reporter never changes the outcome of a test or a class: if its own work fails in any callback, the error is
 * logged as a warning through {@code java.util.logging}, and the test runs on. Only a {@link VirtualMachineError},
 * such as an {@link OutOfMemoryError}, propagates.
 * <p>
 * The extension can be configured through a {@code ctrf.properties} file placed in the classpath.
 * See the README for all available configuration options.
 */
public class CtrfExtension implements TestRunExtension, AfterAllCallback, BeforeEachCallback, TestWatcher {

    private static final ExtensionContext.Namespace NAMESPACE = ExtensionContext.Namespace.create(CtrfExtension.class);
    private static final Logger LOGGER = Logger.getLogger(CtrfExtension.class.getName());
    private static final String GENERATED_BY = "io.github.alexshamrai.jupiter.CtrfExtension";
    private static final String INITIALIZATION_ERROR = "initializationError";
    private static final String TEARDOWN_ERROR = "teardownError";

    private final CtrfReportManager reportManager;

    /**
     * Creates the extension, reporting through the JVM's report manager. JUnit calls this constructor.
     */
    public CtrfExtension() {
        this(CtrfReportManager.getInstance());
    }

    /**
     * Creates the extension with the report manager it reports through, for tests.
     */
    CtrfExtension(CtrfReportManager reportManager) {
        this.reportManager = reportManager;
    }

    @Override
    public void beforeAll(ExtensionContext context) {
        guarded("beforeAll", context, () -> startClass(context));
    }

    private void startClass(ExtensionContext context) {
        TestRunExtension.super.beforeAll(context);
        context.getParent().ifPresent(CtrfExtension::markChildrenStarted);
        context.getStore(NAMESPACE).put(context.getUniqueId(), new ClassState(System.currentTimeMillis()));
    }

    /**
     * Reports the class as failed if it failed outside its tests, and otherwise records that it succeeded, so
     * that its failure in an earlier retry round is reported as recovered: passed and flaky. Runs after the
     * class's {@code @AfterAll} methods, and also when a {@code @BeforeAll} method or a
     * {@code BeforeAllCallback} failed, but not when the class could not be created (see the class
     * documentation).
     *
     * @param context the context of the finished test class
     */
    @Override
    public void afterAll(ExtensionContext context) {
        guarded("afterAll", context, () -> context.getExecutionException().ifPresentOrElse(
            error -> reportClassFailure(context, error),
            () -> reportClassSuccess(context)));
    }

    @Override
    public void beforeAllTests(ExtensionContext context) {
        guarded("beforeAllTests", context, () -> reportManager.startTestRun(GENERATED_BY));
    }

    @Override
    public void afterAllTests(ExtensionContext context) {
        guarded("afterAllTests", context, () -> reportManager.finishTestRun());
    }

    @Override
    public void beforeEach(ExtensionContext context) {
        guarded("beforeEach", context, () -> {
            markChildrenStarted(context);
            reportManager.onTestStart(createTestDetails(context));
        });
    }

    // The watcher callbacks pass the test's full identity: when another extension failed before this
    // extension's beforeEach ran, no start was recorded and the identity would otherwise be lost.
    // For the same reason, and because beforeEach never runs for a disabled test, they also mark the class
    // as having started tests.
    @Override
    public void testSuccessful(ExtensionContext context) {
        guarded("testSuccessful", context, () -> {
            markChildrenStarted(context);
            reportManager.onTestSuccess(createTestDetails(context));
        });
    }

    @Override
    public void testFailed(ExtensionContext context, Throwable cause) {
        guarded("testFailed", context, () -> {
            markChildrenStarted(context);
            reportManager.onTestFailure(createTestDetails(context), cause);
        });
    }

    @Override
    public void testAborted(ExtensionContext context, Throwable cause) {
        guarded("testAborted", context, () -> {
            markChildrenStarted(context);
            reportManager.onTestAborted(createTestDetails(context), cause);
        });
    }

    @Override
    public void testDisabled(ExtensionContext context, Optional<String> reason) {
        guarded("testDisabled", context, () -> {
            markChildrenStarted(context);
            reportManager.onTestSkipped(createTestDetails(context), reason);
        });
    }

    private void reportClassFailure(ExtensionContext context, Throwable error) {
        ClassState state = classStateOf(context);
        String name = state != null && state.childrenStarted() ? TEARDOWN_ERROR : INITIALIZATION_ERROR;
        long startTime = state != null ? state.startTime() : System.currentTimeMillis();
        String uniqueId = context.getUniqueId();
        String className = context.getTestClass()
            .map(Class::getName)
            .orElse(context.getDisplayName());

        reportManager.onTestStart(new TestDetails(startTime, context.getTags(), className, uniqueId, name));
        reportManager.onTestFailure(uniqueId, error);
    }

    private void reportClassSuccess(ExtensionContext context) {
        ClassState state = classStateOf(context);
        reportManager.onContainerSuccess(context.getUniqueId(), state != null ? state.startTime() : null);
    }

    /**
     * Runs reporter work so that it can't change the outcome of a test or a class: anything it throws is logged as a
     * warning and dropped, except a {@link VirtualMachineError}, which the JVM can't recover from.
     */
    private static void guarded(String callback, ExtensionContext context, Runnable work) {
        try {
            work.run();
        } catch (VirtualMachineError e) {
            throw e;
        } catch (Throwable e) {
            LOGGER.log(Level.WARNING, e, () -> "The CTRF reporter failed in " + callback + " of " + uniqueIdOf(context)
                + "; the test's outcome is unchanged, but the report may miss it");
        }
    }

    private static String uniqueIdOf(ExtensionContext context) {
        try {
            return context.getUniqueId();
        } catch (RuntimeException e) {
            return "a context without a unique ID";
        }
    }

    /**
     * Marks the nearest enclosing class, starting at the given context, as having started tests.
     */
    private static void markChildrenStarted(ExtensionContext from) {
        for (Optional<ExtensionContext> context = Optional.of(from); context.isPresent(); context = context.get().getParent()) {
            ClassState state = classStateOf(context.get());
            if (state != null) {
                state.markChildrenStarted();
                return;
            }
        }
    }

    // Keyed by the class's own unique ID: the store lookup falls back to parent stores, and a nested
    // class must not pick up its outer class's state.
    private static ClassState classStateOf(ExtensionContext context) {
        return context.getStore(NAMESPACE).get(context.getUniqueId(), ClassState.class);
    }

    private TestDetails createTestDetails(ExtensionContext context) {
        return TestDetails.fromAdapter(new ExtensionContextAdapter(context));
    }
}
```

```java
/**
 * One run's state: what started it, the entry point that reports it, when it started, and what it recorded so far.
 * <p>
 * The owner is the listener's {@code TestPlan} or the extension's root {@code ExtensionContext}, compared by identity.
 * Only the owner can end the run, so a JUnit run started from inside a test can't end the run around it (CB-2).
 */
final class TestRun {

    private final Object owner;
    private final String generator;
    private final long startTime;
    private final TestStateTracker state = new TestStateTracker();

    TestRun(Object owner, String generator, long startTime) {
        this.owner = owner;
        this.generator = generator;
        this.startTime = startTime;
    }

    Object owner() {
        return owner;
    }

    String generator() {
        return generator;
    }

    long startTime() {
        return startTime;
    }

    /**
     * Returns the attempts, the container successes and the tests in progress recorded so far.
     *
     * @return the run's state
     */
    TestStateTracker state() {
        return state;
    }
}
```

```java
package io.github.alexshamrai;

import io.github.alexshamrai.config.ConfigReader;
import io.github.alexshamrai.ctrf.model.Test;
import io.github.alexshamrai.model.TestDetails;
import io.github.alexshamrai.util.SummaryUtil;

import java.util.List;
import java.util.Objects;
import java.util.Optional;
import java.util.Set;
import java.util.concurrent.atomic.AtomicBoolean;
import java.util.concurrent.atomic.AtomicReference;
import java.util.function.Consumer;

import static io.github.alexshamrai.ctrf.model.Test.TestStatus.FAILED;
import static io.github.alexshamrai.ctrf.model.Test.TestStatus.PASSED;
import static io.github.alexshamrai.ctrf.model.Test.TestStatus.SKIPPED;

/**
 * Coordinates CTRF test report generation and test execution tracking.
 * <p>
 * This class follows the singleton pattern and serves as the main coordinator
 * for the CTRF reporting library. It delegates specific responsibilities to
 * specialized classes:
 * <ul>
 *   <li>{@link TestRun} - one run's owner, start time, and the attempts and container successes it recorded</li>
 *   <li>{@link RunIdResolver} - decides which JVMs share one report</li>
 *   <li>{@link ReportMerger} - merges this execution into the report written by the same run</li>
 *   <li>{@link CtrfReportFileService} - reads and writes the report under a lock</li>
 * </ul>
 * <p>
 * At most one run is active, and only its owner can end it. A JUnit run started from inside a test, such as a test
 * that runs JUnit itself, is refused, so it neither ends the run around it nor adds its tests (CB-2).
 */
public final class CtrfReportManager {

    private static final String ABORTED = "aborted";

    /**
     * The owner of the runs started through {@link #startTestRun(String)}, which names none.
     */
    private static final Object UNNAMED_OWNER = new Object();

    private static final CtrfReportManager INSTANCE = new CtrfReportManager();

    private final ConfigReader configReader;
    private final CtrfReportFileService fileService;
    private final TestProcessor testProcessor;
    private final CtrfJsonComposer ctrfJsonComposer;
    private final String runId;

    private final AtomicReference<TestRun> activeRun = new AtomicReference<>();
    private final AtomicBoolean isEnvironmentHealthy = new AtomicBoolean(true);

    private CtrfReportManager() {
        this.configReader = new ConfigReader();
        this.fileService = new CtrfReportFileService(configReader);
        this.testProcessor = new TestProcessor(configReader);
        this.ctrfJsonComposer = null;
        this.runId = RunIdResolver.resolve(configReader);

        if (EnvironmentHealthTracker.isEnvironmentVariableUnhealthy()) {
            isEnvironmentHealthy.set(false);
        }
    }

    /**
     * Package-private constructor for testing purposes, allowing dependency injection.
     */
    CtrfReportManager(ConfigReader configReader,
                      CtrfReportFileService ctrfReportFileService,
                      TestProcessor testProcessor,
                      CtrfJsonComposer ctrfJsonComposer,
                      String runId) {
        this.configReader = configReader;
        this.fileService = ctrfReportFileService;
        this.testProcessor = testProcessor;
        this.ctrfJsonComposer = ctrfJsonComposer;
        this.runId = runId;
    }

    public static CtrfReportManager getInstance() {
        return INSTANCE;
    }

    void markEnvironmentUnhealthyInternal() {
        isEnvironmentHealthy.set(false);
    }

    boolean isEnvironmentHealthyInternal() {
        return isEnvironmentHealthy.get();
    }

    void resetEnvironmentHealthForTesting() {
        isEnvironmentHealthy.set(true);
    }

    public void onTestStart(TestDetails testDetails) {
        TestRun run = activeRun.get();
        if (run != null) {
            run.state().putTestDetails(testDetails.uniqueId(), testDetails);
        }
    }

    public void onTestSkipped(TestDetails testDetails, Optional<String> reason) {
        TestRun run = activeRun.get();
        if (run == null) {
            return;
        }
        var test = testProcessor.createTest(testDetails.displayName(), testDetails, testDetails.startTime());
        test.setStatus(SKIPPED);
        reason.ifPresent(test::setMessage);
        run.state().addAttempt(test);
    }

    /**
     * Records a finished test in the active run. The start recorded by {@link #onTestStart} wins; when there is none,
     * the test keeps the identity it was reported with and its start time is the stop time. Does nothing when no run
     * is active.
     */
    private void processTestResult(TestDetails reported, Test.TestStatus status, Consumer<Test> outcomeDetails) {
        TestRun run = activeRun.get();
        if (run == null) {
            return;
        }
        long stopTime = System.currentTimeMillis();
        TestDetails details = run.state().removeTestDetails(reported.uniqueId());
        if (details == null) {
            details = new TestDetails(stopTime, reported.tags(), reported.filePath(), reported.uniqueId(), reported.displayName());
        }

        var newTest = testProcessor.createTest(details.displayName(), details, stopTime);
        newTest.setStatus(status);
        outcomeDetails.accept(newTest);

        run.state().addAttempt(newTest);
    }

    public void onTestSuccess(String uniqueId) {
        onTestSuccess(unknownTest(uniqueId));
    }

    /**
     * Records a passed test.
     *
     * @param testDetails the test's identity, used when no start was recorded for it
     */
    public void onTestSuccess(TestDetails testDetails) {
        processTestResult(testDetails, PASSED, test -> { });
    }

    public void onTestFailure(String uniqueId, Throwable cause) {
        onTestFailure(unknownTest(uniqueId), cause);
    }

    /**
     * Records a failed test.
     *
     * @param testDetails the test's identity, used when no start was recorded for it
     * @param cause       the failure, or {@code null}
     */
    public void onTestFailure(TestDetails testDetails, Throwable cause) {
        processTestResult(testDetails, FAILED, test -> {
            if (cause != null) {
                testProcessor.setFailureDetails(test, cause);
            }
        });
    }

    public void onTestAborted(String uniqueId, Throwable cause) {
        onTestAborted(unknownTest(uniqueId), cause);
    }

    /**
     * Records a test that JUnit aborted, typically because an assumption failed. Like Gradle and Surefire,
     * the report counts it as skipped; {@code rawStatus} keeps JUnit's "aborted" and {@code message} the reason.
     *
     * @param testDetails the test's identity, used when no start was recorded for it
     * @param cause       the exception that aborted the test, or {@code null}
     */
    public void onTestAborted(TestDetails testDetails, Throwable cause) {
        processTestResult(testDetails, SKIPPED, test -> {
            test.setRawStatus(ABORTED);
            if (cause != null) {
                test.setMessage(cause.getMessage());
            }
        });
    }

    /**
     * Records a container that finished without failing, such as a test class whose {@code @BeforeAll} and
     * {@code @AfterAll} methods passed. If the same container failed in an earlier retry round, its failure is
     * then reported as recovered. Does nothing when no run is active.
     *
     * @param uniqueId  the container's JUnit unique ID
     * @param startTime when the container started, or {@code null} if unknown; the stop time is used then
     */
    public void onContainerSuccess(String uniqueId, Long startTime) {
        TestRun run = activeRun.get();
        if (run == null) {
            return;
        }
        long stopTime = System.currentTimeMillis();
        run.state().addContainerSuccess(new ContainerSuccess(uniqueId, startTime != null ? startTime : stopTime, stopTime));
    }

    /**
     * The identity of a test known only by its unique ID, for callers that recorded its start beforehand.
     */
    private static TestDetails unknownTest(String uniqueId) {
        return new TestDetails(0L, Set.of(), null, uniqueId, "Unknown Test");
    }

    /**
     * Starts recording a run whose caller names no owner. All such calls share one owner, so they behave as in 0.5.0;
     * the entry points use {@link #startTestRun(Object, String)}.
     *
     * @param generator the entry point that reports, written as {@code generatedBy}
     */
    public void startTestRun(String generator) {
        startTestRun(UNNAMED_OWNER, generator);
    }

    /**
     * Starts recording a run owned by {@code owner}, unless another owner's run is active. Reads no file: the report
     * is read only at the end, under the lock.
     *
     * @param owner     what starts the run, compared by identity: the listener's {@code TestPlan} or the extension's
     *                  root {@code ExtensionContext}
     * @param generator the entry point that reports, written as {@code generatedBy}
     * @return whether {@code owner} owns the active run: true if the run was just started or {@code owner} started it
     *     before, false if another owner's run is active, as for a JUnit run started from inside a test
     */
    public boolean startTestRun(Object owner, String generator) {
        Objects.requireNonNull(owner, "owner");
        TestRun candidate = new TestRun(owner, generator, System.currentTimeMillis());
        while (true) {
            if (activeRun.compareAndSet(null, candidate)) {
                return true;
            }
            TestRun active = activeRun.get();
            if (active != null) {
                return active.owner() == owner;
            }
        }
    }

    /**
     * Writes the results of the run started through {@link #startTestRun(String)}, if it is the active run.
     */
    public void finishTestRun() {
        finishTestRun(UNNAMED_OWNER);
    }

    /**
     * Writes the results of the run {@code owner} owns, and ends it. Does nothing if {@code owner} doesn't own the
     * active run. The report on disk is read while it is locked: if it was written by the same run, for example by a
     * parallel fork or an earlier retry round, this execution is merged into it; otherwise it is replaced.
     *
     * @param owner the owner given to {@link #startTestRun(Object, String)}
     */
    public void finishTestRun(Object owner) {
        TestRun run = activeRun.get();
        if (run == null || run.owner() != owner || !activeRun.compareAndSet(run, null)) {
            return;
        }

        long testRunStopTime = System.currentTimeMillis();
        refreshEnvironmentHealthFromEnvVar();

        List<Test> attempts = run.state().getAllAttempts();
        List<ContainerSuccess> successes = run.state().getAllContainerSuccesses();
        long startTime = run.startTime();
        boolean healthy = isEnvironmentHealthy.get();
        CtrfJsonComposer composer = composer(run.generator());

        fileService.update(existing -> {
            var merged = ReportMerger.merge(existing, runId, attempts, successes, startTime, testRunStopTime, healthy);
            var summary = SummaryUtil.createSummary(merged.tests(), merged.start(), merged.stop());
            return composer.generateCtrfJson(summary, merged.tests(), merged.healthy(), runId);
        });
    }

    private CtrfJsonComposer composer(String generator) {
        return ctrfJsonComposer != null
            ? ctrfJsonComposer
            : new CtrfJsonComposer(configReader, new StartupDurationProcessor(), generator);
    }

    private void refreshEnvironmentHealthFromEnvVar() {
        if (EnvironmentHealthTracker.isEnvironmentVariableUnhealthy()) {
            isEnvironmentHealthy.set(false);
        }
    }
}
```

```java
/**
 * JUnit 5 extension that generates test reports in the CTRF (Common Test Report Format) format.
 * <p>
 * This extension tracks test execution, captures test results, and generates a JSON report
 * following the CTRF standard. It handles test statuses, and captures relevant test metadata.
 * <p>
 * To use this extension, simply add it to your test class using the {@code @ExtendWith} annotation:
 * <pre>
 * {@code
 * @ExtendWith(CtrfExtension.class)
 * public class MyTest {
 * // test methods
 * }
 * }
 * </pre>
 * <p>
 * A failure of a whole test class is reported as one failed entry for that class, identified by the class's
 * unique ID: "initializationError" when the class failed before any of its tests started or were skipped
 * (for example in {@code @BeforeAll} or in another extension's {@code BeforeAllCallback}), "teardownError"
 * when it failed afterwards (for example in {@code @AfterAll}).
 * <p>
 * The extension learns about a class failure only when JUnit runs the class's {@code AfterAllCallback}s,
 * so it cannot see:
 * <ul>
 *   <li>a class that could not be created: with {@code @TestInstance(Lifecycle.PER_CLASS)}, a failing
 *       constructor or {@code TestInstancePostProcessor} (for example a Spring context that fails to load)
 *       stops the class before any callback runs, and the report shows no failure for it;</li>
 *   <li>failures of containers below class level, such as a {@code @MethodSource} that throws;</li>
 *   <li>teardown failures of extensions registered before it, whose callbacks run after its own.</li>
 * </ul>
 * The JUnit Platform listener {@code io.github.alexshamrai.launcher.CtrfListener} reports all of these.
 * <p>
 * Tests of a class that JUnit skips as a whole, such as a {@code @Disabled} class or a class disabled by a
 * class-level condition, never reach the extension and are missing from its report. The JUnit Platform
 * listener {@code io.github.alexshamrai.launcher.CtrfListener} reports them as skipped.
 * <p>
 * Only one run is reported at a time. The run belongs to the root context that started it; the extension reports
 * nothing for the classes of a JUnit run that a test starts itself, and the run around it goes on.
 * <p>
 * The reporter never changes the outcome of a test or a class: if its own work fails in any callback, the error is
 * logged as a warning through {@code java.util.logging}, and the test runs on. Only a {@link VirtualMachineError},
 * such as an {@link OutOfMemoryError}, propagates.
 * <p>
 * The extension can be configured through a {@code ctrf.properties} file placed in the classpath.
 * See the README for all available configuration options.
 */
public class CtrfExtension implements TestRunExtension, AfterAllCallback, BeforeEachCallback, TestWatcher {

    /**
     * Key, in the root context's store, of whether that root's run is the one being reported.
     */
    static final String OWNS_RUN = "ownsRun";

    private static final ExtensionContext.Namespace NAMESPACE = ExtensionContext.Namespace.create(CtrfExtension.class);
    private static final Logger LOGGER = Logger.getLogger(CtrfExtension.class.getName());
    private static final String GENERATED_BY = "io.github.alexshamrai.jupiter.CtrfExtension";
    private static final String INITIALIZATION_ERROR = "initializationError";
    private static final String TEARDOWN_ERROR = "teardownError";

    private final CtrfReportManager reportManager;

    /**
     * Creates the extension, reporting through the JVM's report manager. JUnit calls this constructor.
     */
    public CtrfExtension() {
        this(CtrfReportManager.getInstance());
    }

    /**
     * Creates the extension with the report manager it reports through, for tests.
     */
    CtrfExtension(CtrfReportManager reportManager) {
        this.reportManager = reportManager;
    }

    @Override
    public void beforeAll(ExtensionContext context) {
        guarded("beforeAll", context, () -> startClass(context));
    }

    private void startClass(ExtensionContext context) {
        TestRunExtension.super.beforeAll(context);
        if (ownsRun(context)) {
            context.getParent().ifPresent(CtrfExtension::markChildrenStarted);
            context.getStore(NAMESPACE).put(context.getUniqueId(), new ClassState(System.currentTimeMillis()));
        }
    }

    /**
     * Reports the class as failed if it failed outside its tests, and otherwise records that it succeeded, so
     * that its failure in an earlier retry round is reported as recovered: passed and flaky. Runs after the
     * class's {@code @AfterAll} methods, and also when a {@code @BeforeAll} method or a
     * {@code BeforeAllCallback} failed, but not when the class could not be created (see the class
     * documentation).
     *
     * @param context the context of the finished test class
     */
    @Override
    public void afterAll(ExtensionContext context) {
        reportIfOwner("afterAll", context, () -> context.getExecutionException().ifPresentOrElse(
            error -> reportClassFailure(context, error),
            () -> reportClassSuccess(context)));
    }

    /**
     * Starts the run, owned by the root context, and stores in the root's store whether it got the run. A root whose
     * run start is refused, because another run is active, belongs to a JUnit run started from inside a test.
     *
     * @param context the context of the run's first class
     */
    @Override
    public void beforeAllTests(ExtensionContext context) {
        guarded("beforeAllTests", context, () -> {
            ExtensionContext root = context.getRoot();
            root.getStore(NAMESPACE).put(OWNS_RUN, reportManager.startTestRun(root, GENERATED_BY));
        });
    }

    @Override
    public void afterAllTests(ExtensionContext context) {
        reportIfOwner("afterAllTests", context, () -> reportManager.finishTestRun(context.getRoot()));
    }

    @Override
    public void beforeEach(ExtensionContext context) {
        reportIfOwner("beforeEach", context, () -> {
            markChildrenStarted(context);
            reportManager.onTestStart(createTestDetails(context));
        });
    }

    // The watcher callbacks pass the test's full identity: when another extension failed before this
    // extension's beforeEach ran, no start was recorded and the identity would otherwise be lost.
    // For the same reason, and because beforeEach never runs for a disabled test, they also mark the class
    // as having started tests.
    @Override
    public void testSuccessful(ExtensionContext context) {
        reportIfOwner("testSuccessful", context, () -> {
            markChildrenStarted(context);
            reportManager.onTestSuccess(createTestDetails(context));
        });
    }

    @Override
    public void testFailed(ExtensionContext context, Throwable cause) {
        reportIfOwner("testFailed", context, () -> {
            markChildrenStarted(context);
            reportManager.onTestFailure(createTestDetails(context), cause);
        });
    }

    @Override
    public void testAborted(ExtensionContext context, Throwable cause) {
        reportIfOwner("testAborted", context, () -> {
            markChildrenStarted(context);
            reportManager.onTestAborted(createTestDetails(context), cause);
        });
    }

    @Override
    public void testDisabled(ExtensionContext context, Optional<String> reason) {
        reportIfOwner("testDisabled", context, () -> {
            markChildrenStarted(context);
            reportManager.onTestSkipped(createTestDetails(context), reason);
        });
    }

    private void reportClassFailure(ExtensionContext context, Throwable error) {
        ClassState state = classStateOf(context);
        String name = state != null && state.childrenStarted() ? TEARDOWN_ERROR : INITIALIZATION_ERROR;
        long startTime = state != null ? state.startTime() : System.currentTimeMillis();
        String uniqueId = context.getUniqueId();
        String className = context.getTestClass()
            .map(Class::getName)
            .orElse(context.getDisplayName());

        reportManager.onTestStart(new TestDetails(startTime, context.getTags(), className, uniqueId, name));
        reportManager.onTestFailure(uniqueId, error);
    }

    private void reportClassSuccess(ExtensionContext context) {
        ClassState state = classStateOf(context);
        reportManager.onContainerSuccess(context.getUniqueId(), state != null ? state.startTime() : null);
    }

    /**
     * Runs reporter work, guarded, only for a context whose root owns the run.
     */
    private static void reportIfOwner(String callback, ExtensionContext context, Runnable work) {
        guarded(callback, context, () -> {
            if (ownsRun(context)) {
                work.run();
            }
        });
    }

    private static boolean ownsRun(ExtensionContext context) {
        return Boolean.TRUE.equals(context.getRoot().getStore(NAMESPACE).get(OWNS_RUN, Boolean.class));
    }

    /**
     * Runs reporter work so that it can't change the outcome of a test or a class: anything it throws is logged as a
     * warning and dropped, except a {@link VirtualMachineError}, which the JVM can't recover from.
     */
    private static void guarded(String callback, ExtensionContext context, Runnable work) {
        try {
            work.run();
        } catch (VirtualMachineError e) {
            throw e;
        } catch (Throwable e) {
            LOGGER.log(Level.WARNING, e, () -> "The CTRF reporter failed in " + callback + " of " + uniqueIdOf(context)
                + "; the test's outcome is unchanged, but the report may miss it");
        }
    }

    private static String uniqueIdOf(ExtensionContext context) {
        try {
            return context.getUniqueId();
        } catch (RuntimeException e) {
            return "a context without a unique ID";
        }
    }

    /**
     * Marks the nearest enclosing class, starting at the given context, as having started tests.
     */
    private static void markChildrenStarted(ExtensionContext from) {
        for (Optional<ExtensionContext> context = Optional.of(from); context.isPresent(); context = context.get().getParent()) {
            ClassState state = classStateOf(context.get());
            if (state != null) {
                state.markChildrenStarted();
                return;
            }
        }
    }

    // Keyed by the class's own unique ID: the store lookup falls back to parent stores, and a nested
    // class must not pick up its outer class's state.
    private static ClassState classStateOf(ExtensionContext context) {
        return context.getStore(NAMESPACE).get(context.getUniqueId(), ClassState.class);
    }

    private TestDetails createTestDetails(ExtensionContext context) {
        return TestDetails.fromAdapter(new ExtensionContextAdapter(context));
    }
}
```

~~~markdown
`CtrfListener` is a JUnit Platform `TestExecutionListener`. It sees everything the JUnit Platform runs, so besides your tests it also reports:

LauncherDiscoveryRequest request = LauncherDiscoveryRequestBuilder.request()
    .selectors(selectPackage("com.example"))

`CtrfExtension` is a JUnit Jupiter extension. Register it on each test class, or on a base class they share:
~~~
