# HP-12: `suite` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every test in the CTRF report gets `suite`: the display names of its containers, outermost first, without the engine. The listener and the extension agree on it. Retries, forks and recoveries keep it. The integration validator checks it against JUnit's own event log. One branch, `feat/hp-12-suite`, four commits.

**Architecture:**
- Task 1 gives `TestContextAdapter` four default methods: `getContainerNames()`, `getEngineName()`, and the two that hold the rule, `getSuite()` and `getSuiteOfChildren()`. It also gives `TestDetails` a `suite` component and has `TestProcessor` write it.
- Task 2 makes the two adapters compute the container names: the listener's walks the `TestPlan`, the extension's the `ExtensionContext` parents. Both entry points use them, and class errors use `getSuiteOfChildren()`.
- Task 3 carries `suite` through `AttemptFolder.unfold` and HP-11 recoveries.
- Task 4 adds the validator's cross-check against JUnit's event log, a `PaymentsTest` fake class, a compat check, and docs.

**Tech Stack:**
- Java 17 (`--release 17`), built with the JDK 25 toolchain; the tests also run on Java 17 and 21;
- Gradle 9; JUnit 5.10.5 as the compile floor for main code, JUnit 6.1.3 for tests;
- Lombok, Mockito 5, AssertJ;
- Jackson 3 (test scope only).

## Notes on choices this plan makes

- **The compat check of `suite`,** in Task 4, goes beyond the spec's test list. It's the only place where real JUnit 4 tests run through Vintage, Review Focus 3.
- **`ExtSuiteFixture` has no `@TestFactory`.** JUnit runs no extension callbacks for dynamic tests, so the extension reports none, and the comparison of the two entry points leaves the listener's dynamic entries out.
- **Scenario assertions identify entries by `testId` segments, not by display names,** for parameterized and repeated invocations. Their display names depend on JUnit's default patterns and on the compiler's `-parameters` flag.

```java
    /**
     * Returns the display names of the containers above this one, outermost first, without the engine.
     *
     * @return the container names; empty by default, and when the engine is the only container above
     */
    default List<String> getContainerNames() {
        return List.of();
    }

    /**
     * Returns the display name of the engine this belongs to: the topmost container, or this one if nothing is above it.
     *
     * @return the engine's display name; empty by default
     */
    default Optional<String> getEngineName() {
        return Optional.empty();
    }

    /**
     * Returns the CTRF {@code suite}: the container names, or the engine's name when there are none.
     *
     * @return the suite, outermost first; empty when neither containers nor the engine are known
     */
    default List<String> getSuite() {
        List<String> containers = getContainerNames();
        if (!containers.isEmpty()) {
            return containers;
        }
        return getEngineName().map(List::of).orElse(List.of());
    }

    /**
     * Returns the suite of what this container holds: its container names followed by its own display name. A class's
     * "initializationError" or "teardownError" entry gets it, so that it's grouped with the class's tests.
     *
     * @return the suite, outermost first; it never falls back to the engine's name
     */
    default List<String> getSuiteOfChildren() {
        List<String> suite = new ArrayList<>(getContainerNames());
        suite.add(getDisplayName());
        return suite;
    }
```

```java
public record TestDetails(
    long startTime,
    Set<String> tags,
    String filePath,
    String uniqueId,
    String displayName,
    List<String> suite
) {

    /**
     * Creates TestDetails. The suite is copied; {@code null} means none, as an empty list does.
     */
    public TestDetails {
        suite = suite == null ? List.of() : List.copyOf(suite);
    }

    /**
     * Creates TestDetails without a suite.
     *
     * @param startTime   when the test started
     * @param tags        the test's tags
     * @param filePath    the test's class, or {@code null}
     * @param uniqueId    the JUnit unique ID
     * @param displayName the test's display name
     */
    public TestDetails(long startTime, Set<String> tags, String filePath, String uniqueId, String displayName) {
        this(startTime, tags, filePath, uniqueId, displayName, List.of());
    }

    /**
     * Creates TestDetails from a test context adapter.
     * <p>
     * This static factory method extracts all relevant test metadata (unique ID, display name,
     * tags, source location, suite) from the adapter and constructs a TestDetails record with the
     * current timestamp as the start time.
     *
     * @param adapter the test context adapter
     * @return the constructed TestDetails
     */
    public static TestDetails fromAdapter(TestContextAdapter adapter) {
        return new TestDetails(
            System.currentTimeMillis(),
            adapter.getTags(),
            adapter.getSourceLocation().orElse(null),
            adapter.getUniqueId(),
            adapter.getDisplayName(),
            adapter.getSuite()
        );
    }
}
```

```java
    void listenerGroupsEveryEntryByItsContainers() throws Exception {

        assertNestedSuites(result);
        assertThat(suitesWithin(result, "[test-factory:generated()]")).singleElement()
            .isEqualTo(List.of("Payments", "generated()", "group"));

    @org.junit.jupiter.api.Test
    void extensionGroupsEveryEntryByItsContainers() throws Exception {
        assertNestedSuites(ScenarioRunner.runWithExtension(ExtSuiteFixture.class));
    }

    @org.junit.jupiter.api.Test
    void listenerAndExtensionGiveTheSameSuites() throws Exception {
        Map<String, List<String>> listener = suitesById(ScenarioRunner.runWithListener(SuiteFixture.class), "SuiteFixture");
        Map<String, List<String>> extension = suitesById(ScenarioRunner.runWithExtension(ExtSuiteFixture.class), "ExtSuiteFixture");
        listener.keySet().removeIf(testId -> testId.contains("[test-factory:"));

        assertThat(extension).isEqualTo(listener);
    }

    @org.junit.jupiter.api.Test
    void listenerGroupsClassErrorsAndTestsOfASkippedClassUnderTheirClass() throws Exception {
        var result = ScenarioRunner.runWithListener(SetupAlwaysFailsFixture.class, AfterAllFailureFixture.class,
            DisabledClassFixture.class);

        assertThat(result.tests())
            .extracting(Test::getName, Test::getSuite)
            .containsExactlyInAnyOrder(
                tuple("initializationError", List.of("SetupAlwaysFailsFixture")),
                tuple("ok()", List.of("AfterAllFailureFixture")),
                tuple("teardownError", List.of("AfterAllFailureFixture")),
                tuple("one()", List.of("DisabledClassFixture")),
                tuple("two()", List.of("DisabledClassFixture")));
    }

    @org.junit.jupiter.api.Test
    void extensionGroupsClassErrorsUnderTheirClass() throws Exception {
        var result = ScenarioRunner.runWithExtension(ExtSetupAlwaysFailsFixture.class,
            ExtAfterAllFailureWithDisabledTestsFixture.class);

        assertThat(result.tests())
            .extracting(Test::getName, Test::getSuite)
            .containsExactlyInAnyOrder(
                tuple("initializationError", List.of("ExtSetupAlwaysFailsFixture")),
                tuple("disabled()", List.of("ExtAfterAllFailureWithDisabledTestsFixture")),
                tuple("teardownError", List.of("ExtAfterAllFailureWithDisabledTestsFixture")));
    }

    private static void assertNestedSuites(ScenarioRunner.Result result) {
        assertThat(suiteOf(result, "/[method:charges()]")).containsExactly("Payments");
        assertThat(suiteOf(result, "/[nested-class:Refunds]/[method:refundsTheFee()]")).containsExactly("Payments", "Refunds");
        assertThat(suitesWithin(result, "[test-template:refundsEachAmount(int)]"))
            .hasSize(2)
            .allSatisfy(suite -> assertThat(suite).containsExactly("Payments", "Refunds", "refundsEachAmount(int)"));
        assertThat(suitesWithin(result, "[test-template:refundsTwice()]"))
            .hasSize(2)
            .allSatisfy(suite -> assertThat(suite).containsExactly("Payments", "Refunds", "refundsTwice()"));
        assertThat(suiteOf(result, "/[nested-class:Broken]")).containsExactly("Payments", "Broken");
    }

    private static List<String> suiteOf(ScenarioRunner.Result result, String testIdEnd) {
        var matches = result.tests().stream().filter(test -> test.getTestId().endsWith(testIdEnd)).toList();
        assertThat(matches).as("entries whose testId ends with %s", testIdEnd).hasSize(1);
        return matches.get(0).getSuite();
    }

    private static List<List<String>> suitesWithin(ScenarioRunner.Result result, String segment) {
        return result.tests().stream().filter(test -> test.getTestId().contains(segment)).map(Test::getSuite).toList();
    }

    // The fixtures' class names differ, so their testIds are compared without them
    private static Map<String, List<String>> suitesById(ScenarioRunner.Result result, String fixture) {
        Map<String, List<String>> suites = new TreeMap<>();
        result.tests().forEach(test -> suites.put(test.getTestId().replace("." + fixture + "]", ".Fixture]"), test.getSuite()));
        return suites;
    }
}
```

```java
        if (plan == null) {

        List<String> names = new ArrayList<>();
        Optional<TestIdentifier> parent = plan.getParent(identifier);
        while (parent.isPresent()) {

            if (grandparent.isEmpty()) {
```

```java
    /**
     * The {@code suite} the report must give the entry for {@code testId}, by the names in JUnit's log: the display
     * names of the containers above it, outermost first, without the engine, or the engine's name when there are none.
     * A class error, an entry named "initializationError" or "teardownError", is grouped under its class: the class's
     * own name comes last, and the engine's name is never used.
     *
     * @param testId    the entry's unique ID
     * @param entryName the entry's name in the report
     * @return the suite, or empty if JUnit never started {@code testId}
     */
    public Optional<List<String>> expectedSuite(String testId, String entryName) {
        Node node = nodes.get(testId);
        if (node == null) {
            return Optional.empty();
        }
        List<String> containers = new ArrayList<>();
        String engine = node.name();
        Node current = node;
        while (current.parent() != null && nodes.containsKey(current.parent())) {
            Node parent = nodes.get(current.parent());
            if (parent.parent() == null) {
                engine = parent.name();
                break;
            }
            containers.add(0, parent.name());
            current = parent;
        }
        if (CLASS_ERRORS.contains(entryName)) {
            containers.add(node.name());
            return Optional.of(containers);
        }
        return Optional.of(containers.isEmpty() ? List.of(engine) : containers);
    }
```
